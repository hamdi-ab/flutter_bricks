# 1.0.0

- Initial release
- `AppLocale` enum for type-safe locale handling
- `LocaleController` Riverpod notifier for state management
- `LocaleStorage` for persistence via SharedPreferences
- ARB files for English and Arabic (RTL example)
- BuildContext extensions for easy access (`context.l10n`, `context.isRtl`)
- `l10n.yaml` configuration for `flutter gen-l10n`
