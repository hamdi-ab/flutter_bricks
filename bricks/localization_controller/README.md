# Localization Controller 🌍

A robust Flutter localization brick with locale persistence, Riverpod state management, and ARB-based translations.

## Features

- **Type-Safe Locales**: `AppLocale` enum with utility methods
- **Persistence**: Remember user's language preference via SharedPreferences
- **Riverpod Integration**: `LocaleController` AsyncNotifier for state management
- **ARB Code Generation**: Compatible with `flutter gen-l10n`
- **RTL Support**: Arabic locale included as example
- **Context Extensions**: `context.l10n`, `context.isRtl` for convenience

## Installation

```bash
mason add localization_controller --git-url https://github.com/hamdi-ab/flutter_bricks.git --git-path bricks/localization_controller
```

## Usage

### 1. Generate the Brick

```bash
mason make localization_controller
```

### 2. Add Dependencies

Add to your `pubspec.yaml`:

```yaml
dependencies:
  flutter_localizations:
    sdk: flutter
  intl: ^0.19.0

flutter:
  generate: true
```

### 3. Run Code Generation

```bash
# Generate Riverpod providers
dart run build_runner build --delete-conflicting-outputs

# Generate localizations
flutter gen-l10n
```

### 4. Integrate with MaterialApp

```dart
import 'package:your_app/core/l10n/l10n.dart';
import 'package:your_app/core/l10n/generated/app_localizations.dart';

class MyApp extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final localeAsync = ref.watch(localeControllerProvider);
    
    return MaterialApp(
      // Localization Configuration
      localizationsDelegates: AppLocalizations.localizationsDelegates,
      supportedLocales: AppLocalizations.supportedLocales,
      locale: localeAsync.valueOrNull?.locale,
      // ...
    );
  }
}
```

### 5. Change Locale

```dart
// In any widget
ref.read(localeControllerProvider.notifier).setLocale(AppLocale.ar);

// Toggle between locales
ref.read(localeControllerProvider.notifier).toggleLocale();

// Reset to default
ref.read(localeControllerProvider.notifier).resetToDefault();
```

### 6. Access Translations

After running `flutter gen-l10n`, uncomment the import in `l10n_extensions.dart`:

```dart
// Use context extension
Text(context.l10n.settings)

// Check RTL
if (context.isRtl) {
  // Handle RTL layout
}
```

## Adding New Locales

1. Create a new ARB file (e.g., `app_es.arb`) in `lib/core/l10n/arb/`
2. Add the locale to `AppLocale` enum in `app_locale.dart`:
   ```dart
   enum AppLocale {
     en(Locale('en')),
     ar(Locale('ar')),
     es(Locale('es')); // Add new locale
     // ...
   }
   ```
3. Run `flutter gen-l10n`

## File Structure

```
lib/core/l10n/
├── app_locale.dart          # Locale enum
├── l10n.dart                # Barrel file
├── l10n_extensions.dart     # Context extensions
├── locale_controller.dart   # Riverpod controller
├── locale_storage.dart      # Storage interface
├── locale_storage_impl.dart # SharedPreferences impl
├── arb/
│   ├── app_en.arb          # English translations
│   └── app_ar.arb          # Arabic translations (RTL)
└── generated/              # Generated by flutter gen-l10n
    └── app_localizations.dart
```
